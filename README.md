# AI Resume Screener

A Streamlit application that helps compare resumes with a job description using semantic similarity and skill matching.

## Features

- Enter a job description.
- Upload multiple resumes in PDF or DOCX format.
- Extract text from uploaded resumes.
- Calculate semantic similarity between each resume and the job description using Sentence Transformers.
- Detect skills from a predefined keyword list.
- Rank resumes by similarity score.
- Display results in a table and chart.
- Show rule-based explanations with matched and not-detected skills.
- Download screening results as a CSV file.

## Tech Stack

- Python
- Streamlit
- Sentence Transformers (`all-MiniLM-L6-v2`)
- scikit-learn
- pandas
- pypdf
- python-docx

## Run Locally

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd ai-resume-screener
```

Replace `<YOUR_GITHUB_REPOSITORY_URL>` with your repository URL.

### 2. Create and activate a virtual environment (optional but recommended)

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Start the app

```bash
python -m streamlit run app.py
```

Streamlit will show a local URL, usually `http://localhost:8501`.

## How It Works

1. The user enters a job description and uploads resumes.
2. Text is extracted from PDF or DOCX files.
3. The Sentence Transformer model converts the job description and resume text into embeddings.
4. Cosine similarity is used to calculate a similarity score.
5. A predefined keyword list is used to identify skills found in the job description and resume text.
6. Results are ranked and displayed with explanations, and can be downloaded as a CSV.

## Important Limitations

- A similarity score is **not** a probability that a candidate is suitable, and it should not be treated as a hiring decision.
- Skill detection uses a predefined keyword list. A skill may be present but not detected if it is phrased differently.
- Explanations are rule-based, not generated by a generative AI model.
- Resume screening can be affected by formatting, extraction errors, and document content.
- Review resumes manually and use fair, job-related criteria. Do not make hiring decisions based only on this tool.

## Privacy

Resumes may contain personal information. Only upload documents you are authorized to process. If deploying the app publicly, review the hosting platform's privacy and access settings and avoid storing or sharing candidate data unnecessarily.
